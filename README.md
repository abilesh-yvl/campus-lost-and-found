# 🎓 Campus Lost & Found

A modern web-based platform designed to help students report, search for, and recover lost items around campus.

## 🌐 Live Demo

https://abilesh-yvl.github.io/campus-lost-and-found/

## ✨ Features

- 🔎 Search for lost and found items
- 🏷️ Filter items by category
- 📌 Filter by Lost, Found, and Returned status
- 📷 Upload photos of items
- 📍 Display where an item was lost or found
- 📞 Reveal contact details when needed
- ✅ Mark items as returned
- 📱 Responsive design for mobile and desktop
- ⚡ Interactive interface with no external dependencies

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- SVG Icons
- Git & GitHub
- GitHub Pages
